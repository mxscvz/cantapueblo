# Cantapueblo

Sitio web de Cantapueblo — La Fiesta Coral de América, un encuentro coral
internacional en Mendoza, Argentina, desde 1989.

**Sitio en vivo:** https://mxscvz.github.io/cantapueblo/

Sitio estático, bilingüe (español / inglés), construido con [Jekyll](https://jekyllrb.com/)
y desplegado en GitHub Pages.

Documentación técnica y notas de trabajo: ver [`NOTES.md`](./NOTES.md).
